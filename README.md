# Portfólio Pessoal — Leonardo

Bem-vindo ao meu portfólio pessoal!

Este projeto foi desenvolvido com o objetivo de apresentar minha trajetória na área de tecnologia, compartilhar projetos desenvolvidos durante meus estudos e demonstrar meus conhecimentos em desenvolvimento web.

## Sobre o projeto

O portfólio reúne informações sobre minha formação em Análise e Desenvolvimento de Sistemas, tecnologias que estou estudando, projetos desenvolvidos e formas de contato profissional.

A interface foi construída com foco em simplicidade, organização, acessibilidade e responsividade, utilizando uma identidade visual em tons escuros com detalhes em azul.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização, layouts, animações, efeitos visuais e responsividade.

## Funcionalidades

- Apresentação pessoal e profissional.
- Navegação entre as seções da página.
- Exibição de tecnologias em estudo.
- Galeria de projetos com descrições e links externos.
- Seção de contato com links para e-mail, GitHub e LinkedIn.
- Layout responsivo para diferentes tamanhos de tela.
- Efeitos de interação e destaque nos elementos.
